# 任务统计接口
## 要实现
在 storage.py 新增 stats()，返回包含 total 和 done 两个整数的字典。
total 为全部任务数，done 为已完成任务数；空任务集两者均为 0。
在 app.py 新增 GET /tasks/stats，返回上述统计结果，HTTP 状态码为 200。
## 不能改
不修改 CLI、依赖配置或运行期数据文件 tasks.json。
保持现有任务接口行为兼容。
## 已定技术决策
沿用现有存储方式、完成状态字段及 Web 框架。
接口调用 storage.stats() 获取统计，避免重复实现统计逻辑。
确保静态统计路由不被任务 ID 路由匹配。
存储实现与接口存在顺序依赖，作为一个任务交付。
