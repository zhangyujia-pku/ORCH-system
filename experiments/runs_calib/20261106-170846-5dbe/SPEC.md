# 可靠持久化
## 要实现
任务数据保存到本地 JSON 文件，应用重启后恢复数据。
数据文件不存在时返回空列表；中文内容完整往返。
损坏 JSON 或读写失败时明确报错，不覆盖已有数据。
保存使用同目录临时文件与原子替换，失败时清理临时文件。
补充持久化测试与使用说明。
## 不能改
不修改 requirements.txt、.gitignore，不提交运行期数据 tasks.json。
保留现有应用与 CLI 的公开接口。
## 已定的技术决策
沿用 Python、现有 storage.py 与 JSON 文件存储，不引入新依赖。
持久化实现、调用接入、测试与文档存在顺序依赖，合并为一个任务。
