# 任务 CSV 导出
## 要实现
在 app.py 增加 GET /tasks/export，从 storage.py 现有任务读取接口获取列表，返回 CSV。
CSV 包含任务 ID、标题、完成状态三列，按此顺序输出表头及数据；字段映射沿用现有任务模型。
空列表仍输出表头；任务顺序沿用存储返回顺序。
## 不能改
不修改 storage.py、cli.py、存储格式或现有 HTTP 接口行为。
不提交运行期数据、缓存或日志。
## 已定的技术决策
沿用现有 HTTP 框架，在 app.py 中组装响应。
使用 Python 标准库 csv 生成 CSV，采用 UTF-8 编码，响应 Content-Type 为 text/csv。
使用现有测试体系验证导出内容、转义及路由兼容性。
本需求属于单一路由改动，实施与测试合并为一个任务。
