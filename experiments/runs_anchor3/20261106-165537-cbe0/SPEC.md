# 任务列表分页
## 要实现
仅为 storage.py 的任务列表读取入口增加分页能力。
支持 offset 和 limit：offset 默认 0，limit 默认 None；未指定分页参数时返回完整列表。
分页结果等于原有顺序列表的切片；offset 超出范围时返回空列表，limit 为 0 时返回空列表。
offset 和 limit 仅接受非负整数，limit 额外允许 None；非法值抛出 ValueError，布尔值视为非法值。
## 不能改
不修改 app.py、cli.py、持久化格式、运行期数据或其他接口行为。
保留任务列表原有返回类型、排序和筛选语义，先筛选再分页。
## 已定的技术决策
沿用现有 Python 实现和存储方式，不增加依赖。
分页参数采用可选关键字参数，兼容现有调用。
当前输入未提供此前讨论的具体参数约定，本规格使用上述最小兼容约定。
完成后列出实际修改文件、行为变化和测试结果，供用户复测。
