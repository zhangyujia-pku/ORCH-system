# 导出任务列表
## 要实现
在 storage.py 中增加任务列表导出能力，将当前任务列表写入表格文件。
优先沿用 README.md 或现有代码中已明确的导出约定；若未定义格式，采用 UTF-8 BOM 编码的 CSV。
导出列沿用现有任务数据模型中的字段，列顺序固定，每个任务对应一行。
空列表仍输出表头；包含中文、逗号、引号和换行的字段必须可正确回读。
## 不能改
不修改 app.py、cli.py、requirements.txt 或现有接口的签名、返回值及异常行为。
导出不得修改内存中的任务列表或持久化任务数据。
不将运行期生成的表格、任务数据或缓存纳入提交。
## 已定的技术决策
导出逻辑集中在 storage.py，复用现有任务读取机制。
CSV 使用 Python 标准库 csv，不引入依赖。
新增导出入口与现有接口隔离，文件写入失败时向调用者报告异常。
补充自动化测试，完成后报告修改文件、导出调用方式和测试结果。
