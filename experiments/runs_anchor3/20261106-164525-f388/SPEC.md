# 任务软删除
## 要实现什么
删除任务时只标记记录，不从存储中移除原始记录。
正常查询不展示已删除任务，删除接口维持现有响应约定。
完成后说明修改文件与具体改动，由用户再次运行测试确认。
## 不能改什么
不改 CLI、依赖、无关接口或其它业务逻辑。
不直接修改 tasks.json、缓存或其它运行期数据。
## 已定的技术决策
沿用现有 Python 项目与存储方式，在 storage.py 和 app.py 的现有任务流程内实现软删除。
保留原始任务字段，以删除标记区分已删除记录；缺少标记的历史记录视为未删除。
其它接口的响应格式、状态码和未删除任务的行为保持现有约定。
实现与回归测试属于同一项相互依赖的改动，不拆分任务。
