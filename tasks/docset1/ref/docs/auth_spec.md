# 鉴权规格

## 概述
本文件规定鉴权模块对外行为与边界，供研发与测试共同引用。

## 适用范围
- 适用于鉴权模块的所有对外服务与内部调用。
- 不适用于运维脚本与一次性数据修复。

## 条款

### R-AUTH-01 入参与校验
- 输入：鉴权请求体，字段见《字段字典》。
- 输出：鉴权结果对象，含状态与数据。
- 错误码：参数错误返回 400，未授权返回 401，超时返回 504。

### R-AUTH-02 返回结构
- 输入：鉴权请求体，字段见《字段字典》。
- 输出：鉴权结果对象，含状态与数据。
- 错误码：参数错误返回 400，未授权返回 401，超时返回 504。

### R-AUTH-03 失败与重试
- 输入：鉴权请求体，字段见《字段字典》。
- 输出：鉴权结果对象，含状态与数据。
- 错误码：参数错误返回 400，未授权返回 401，超时返回 504。

请求 -> 200 -> 结果对象
